# 居家照护计划变更与服务履约分析

以下资料为合成记录，不含实际个人信息。文件以 UTF-8 编码，普通字段含日期或本地时间（东八区），分号表示同一字段的多值。空值表示在该记录中未提供，不自动当零。表内的凭据编号用于核对记录归属。

## 数据来源

- `data/obligations.csv`：已经签署逐期约定；各期、补访窗口的右端不含，提前取消按小时。
- `data/visits.csv`：联合回执及更正，前序版本通过 replaces 引用。
- `data/windows.csv`：每户可接访窗口及暂停协议。
- `data/roster.csv`：可兑现的班次及病假凭据；两个站点可共享同一实班。
- `data/promises.csv`：已有派工承诺。
- `data/weekly_issue.csv`：已签发周报的账期和数据截止，原始单号由站点提供。

## 环境及检查

使用 Python 3.11.2 标准库，无需网络或额外安装。在项目目录可执行 `python3 -m unittest discover -s tests -v` 核对输入文件、表头与记录形状。各来源字段及记录数量见 `data-contract.json`。目前提供资料读取检查，不生成业务分析结果。
